> レトロなカウントダウンアプリにはもうサヨナラ。広告なしでシンプル＆軽量な **TimeTrace** をぜひお試しください。  
> 本プロジェクトは Android 版 [KIPPU_Trace](https://github.com/KIPPUDESU/KIPPU_Trace) の **SwiftUI** 移植版です。Android 版のデータ構造と直感的な操作感を引き継ぎつつ、iOS 上でさらなる進化と最適化を続けています。  
> **SwiftUI** をベースに設計され、Apple Human Interface Guidelines と自然に融合。このバージョンでも、切符（KIPPU）ならではのこだわりと美意識がたっぷり詰まっています w  

カウントダウン／カウントアップに対応し、未来への楽しみなカウントダウンも、過去の大切な思い出の積み重ねも、人生の特別な瞬間を記録するためのアプリです。

## 主な機能

- **メモリアルカード**：iOS ネイティブデザインを採用。入力したタイトルの文字数に応じて 3 種類のレイアウトが自動で適用されます。
- **ピン留め表示**：大切なイベントをホーム画面の最上部に固定可能。より美しく印象的なデザインで表示されます。
- **詳細ビュー**：背景画像やオーバーレイの濃さを自由にカスタマイズ。フルスクリーンのポスタープレビューで、より没入感のある体験をお届けします w
- **編集プレビュー**：TimeTrace を作成・編集する際、カードと詳細ページの両方の表示効果をリアルタイムで確認できます。
- **テーマ切り替え**：ダークモード／ライトモードに対応。システムテーマにぴったりフィットします。
- **アニメーション切り替え**：アプリ内のトランジションアニメーションのオン／オフを自由に変更できます。
- **多言語対応**：日本語、英語、中国語（簡体字）を標準サポート。今後のアップデートでさらに対応言語を追加予定です。
- **データセキュリティ**：設定内容をワンタップで Zip ファイルとして一括バックアップ。Zip からいつでもカードデータを復元できます。

## Quick Start

### 動作環境
* Xcode 16 以降
* iOS 18.0+ SDK
* Swift 6

### ビルド & 実行
1. リポジトリをクローン：
   ```bash
   git clone [https://github.com/KIPPUDESU/TimeTrace_iOS.git](https://github.com/KIPPUDESU/TimeTrace_iOS.git)
2.	Xcode で TimeTrace-iOS.xcodeproj を開きます
3.	ターゲットとして適切な iOS シミュレータまたは実機を選択します
4.	Run ボタンをクリックしてビルド＆実行します
